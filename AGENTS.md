When adding or changing a feature, update README.md to reflect the change.

This is a quick-config repo: work directly in `~/.hammerspoon` on `main` —
no worktrees, feature branches or pull requests. Hammerspoon loads only
`~/.hammerspoon`, so a change made anywhere else never runs. Commit to `main`
and push; after editing, restart Hammerspoon so the change takes effect.
